# متابعة صحة طفلي – Child Health Tracker (Android)

تطبيق أندرويد لمتابعة الملف الطبي للطفل:

- **التطعيمات**: جدول التطعيمات الإجبارية (وزارة الصحة المصرية) بيتعمل تلقائياً من تاريخ الميلاد، مع حالة كل تطعيم (اتاخد / قريباً / متأخر / لاحقاً)، وتاريخ أخذه، وملاحظات. تقدر تضيف التطعيمات الاختيارية الشائعة أو أي تطعيم تاني، وتعدل أو تحذف أي تطعيم.
- **زيارات الدكتور**: تاريخ ومعاد الزيارة، الدكتور والتخصص والعيادة، السبب والتشخيص، الوزن والطول والحرارة، و**الروشتة** (الأدوية بالجرعة وعدد المرات والمدة) مع صورة الروشتة من الكاميرا أو المعرض. الزيارات الجاية بتظهر لوحدها في "الزيارات القادمة".
- **تذكيرات**: إشعار يومي الساعة 9 الصبح بالتطعيمات المستحقة خلال 3 أيام (أو المتأخرة) وبزيارات الدكتور النهارده أو بكرة.
- **قراءة الروشتة بالذكاء الاصطناعي**: صوّر الروشتة و Claude (من Anthropic) يقرأ التشخيص والأدوية والجرعات ويملأ الخانات وانت تراجعها. محتاج مفتاح API من console.anthropic.com تحطه في صفحة "بيانات الطفل" (بيتحفظ على الموبايل بس ومش بيدخل في النسخ الاحتياطي).
- **قائمة أدوية الأطفال (0–6 سنين)**: اختار الدواء من قائمة بالاسم العلمي والأسماء التجارية المشهورة في مصر بدل ما تكتبه (من غير جرعات، الجرعة حسب وزن الطفل).
- **مشاركة التقرير**: ملخص نصي كامل (التطعيمات والزيارات والروشتات) تقدر تبعته للدكتور على واتساب أو الإيميل.
- الواجهة بالعربي (وبالإنجليزي لو لغة الموبايل إنجليزي). كل البيانات محفوظة على الموبايل بس.

> جدول التطعيمات للاسترشاد فقط — راجع دايماً كارت التطعيم ومكتب الصحة أو طبيب الأطفال.

## نسخة الآيفون

في فولدر [`iphone/`](iphone/) نسخة بتتثبت على الآيفون من Safari (Add to Home Screen) — التفاصيل في [`iphone/README.md`](iphone/README.md).

## تحميل الـ APK

كل push بيشغّل GitHub Actions (`Build APK`) اللي بيبني `app-debug.apk`.
من تبويب **Actions** في الريبو ← آخر تشغيل ← **Artifacts** ← `medical-follow-app-debug`،
فك الضغط وانقل الملف للموبايل وثبّته (لازم تسمح بالتثبيت من مصادر غير معروفة).

## Build locally

Requires Android Studio (or the Android SDK with platform 35) and JDK 17+:

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Tech: Kotlin, Jetpack Compose (Material 3), Room, WorkManager, Navigation Compose, Coil, Anthropic Java SDK (`com.anthropic:anthropic-java`). minSdk 26.
